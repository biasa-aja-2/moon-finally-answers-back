One line, in the voice of the Moon replying at last to the wishes, howls
and late-night promises of everyone staring up at it. The house judge
reads entries two at a time and picks the funniest.

## The line

> Four billion years of wishes, howls, and 2 a.m. promises — and not one
> of you has ever wished me a good night back.

## How it works

`main.py` (pure Python standard library, no dependencies) writes that
single line to `/output/entry.txt`. The line is 1–240 characters, UTF-8,
and a single line of text, as the gate requires.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```

Or point the output elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
